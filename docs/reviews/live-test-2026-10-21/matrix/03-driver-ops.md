# Labby live behaviour matrix — Area 03: DRIVER-OPS (prefix DOPS)

**Area.** Driver application + documents + vehicle + review state machines from the driver app and the admin review queues; document expiry reminders (30/7 d), auto-suspension and renewal; vehicle switch; weekly availability windows; driver performance dashboard + DRV-07 warnings; incentives (weekly 39/40/41 and 59/60/61, peak, rating reward with nightly average and no count); earnings (weekly/monthly, per-trip, trip list + trip detail); balance + floor warning/blocking + settlement unblock; commission tiers; admin driver ledgers.
Not here (owned elsewhere): registration/OTP/login/profile/delete (AUTH), going online/offers/ride lifecycle (RIDE), claim board itself (SCHED-SHARED), fare/receipt math and the settlement/grant forms' own validation (MONEY-GROWTH), report submission + ratings (TRUST-COMMS), RBAC role editing + region form fields (ADMIN), V1 finding-by-finding retests (V1-RETEST-XCUT). Where this area's state changes are only visible on another area's screen, the row names that screen and stays limited to the DRIVER-OPS consequence.

**Sources read.** docs/SRS.md (DRV-01..09, COM-01..04, USR-04/06, RATE-02/03, NFR-S2, §7 defaults); docs/use-cases/driver.md (UC-D-01..05, 15..20), admin.md (UC-A-10/11/12/16/27/29); docs/milestones/M05 (T1..T5 ACs), M08 (T2/T4/T5), M11 (T2/T3), M12 (T4 availability), M15 (T3 rulings Q1..Q6 + review amendments), README tracker (V1 labby-fix Phase A/B notes, M5-T2..T4 decisions); backend/docs/api/onboarding-v1.yaml (header: state machine, review items, files, notifications, driver role; all paths + schema limits), money-v1.yaml (driver ledger, floor, earnings, trip detail, balance, settlements), incentives-v1.yaml (Q1..Q6, W1/W2, H5 nightly average), trust-v1.yaml (driver performance table, warnings, suspension + exemptions, B-W4), scheduled-shared-v1.yaml (availability windows), realtime-v1.yaml (cannotGoOnlineReason, offersBlockedReason); backend NotificationRenderer (EN/AR push copy) + MoneyFloors (status boundaries/notifications) + application.yml (crons/env) + DevRegionSeeder; backend/docs/SEEDING.md; docs/design/canvas/README.md (boards named below); docs/reviews/review-V1-conformance-2026-10-20.md (H5, H6, H7, W3, W4, W19, W21, W31, W43); driver app screens (components/onboarding/*, money/*, incentives/*, trust/performance-screen, scheduled/availability-screen, auth/apply-to-drive-screen, home-screen, settings-screen) + EN/AR translations; admin pages (DriverApplications*, VehicleReviews*, DocumentExpiries, DocumentRenewalDetail, DriverLedgers/DriverLedger, onboarding/*, money/*) + EN/AR strings.
