Driver app: white Labby icon on Labby purple #59128A. Android 12+ draws the splash icon in a 288 dp square and masks it to the central 192 dp circle. The icon sits inside that circle with transparent padding, so no spoke is cropped. iOS and older Android show the same centred icon on the same background. The white icon is the same artwork as labby-icon.png, filled white.
